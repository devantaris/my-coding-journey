OTT App
A modern OTT (Over-The-Top) streaming platform built with Flutter.
Features include user authentication, profile management, movie rentals, watchlist, and genre tracking.


Features
User login and signup
Profile page with avatar, plan, stats, and account options
Continue Watching carousel
Top genres table
Rentals and Watchlist sections
Bottom navigation for easy access to app sections
Getting Started
Clone the repository:


git clone https://github.com/<your-username>/ott_app.git
cd ott_app
Install dependencies:


flutter pub get
Run the app:


flutter run
Directory Structure
lib/ — Main Dart source files
assets/ — Images and posters for movies, banners, and profile
android/, ios/, linux/, macos/, windows/, web/ — Platform-specific files
